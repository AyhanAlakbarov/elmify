# Pre-run reconnaissance — Azerbaijan's State Programme, before `PROMPT-government-outbound-launch.md`

**Date:** 2026-08-29. **Status: NOT a research run, and not an input to one.**

This is a control. `PROMPT-government-outbound-launch.md` is to be run twice, independently, and
adjudicated. **Do not hand this file to either run** — its value is entirely in having been written
first, so the adjudication can ask what each run found *without* it.

**What it is:** a short verified pass over Azerbaijan's Part A, done to size the prompt. Every claim
below was fetched from the issuing body and is quoted. Where a claim rests on a secondary source it
is labelled a lead, not a fact.

---

## 1. The finding that changes what the instrument is

**The State Programme does not admit anyone. It pays for an admission the student already holds.**

From the programme's own FAQ (`dp.edu.az/az/faq`, retrieved 2026-08-29):

> "«2022-2028 Dövlət Proqramı» çərçivəsində xarici ölkələrin ali təhsil müəssisələrinə qəbul həyata
> keçirilmir. Yalnız xarici ali təhsil müəssisələrinə **qəbul olunmuş və yaxud artıq orada təhsil
> alan** tələbələr təhsil xərclərinin qarşılanması məqsədilə … müraciət edə bilərlər."
> — "Admission to foreign higher education institutions is **not** carried out under the 2022-2028
> State Programme. **Only students who have already been admitted to, or are already studying at,**
> foreign HEIs may apply for their study costs to be covered."

**Consequence, and it is not the one the prompt anticipated.** The prompt exists because a downstream
rule bars Azerbaijan from being a portfolio floor on the strength of the *inbound* Heydar Aliyev
grant, and calls that a conflation to correct. The conflation is real (§4). But correcting it does
**not** make the State Programme a floor: **an instrument that produces no admission cannot be a
floor or a safety at all.** It is a funding overlay on a place the student won by themselves.

So the rule's conclusion may survive its broken reasoning. That is worth establishing before anyone
"fixes" the rule — and it is a different modelling object from anything the catalog holds: coverage
conditional on an admission obtained outside the scheme.

## 2. Status, funder and scale — primary-sourced

| Fact | Value | Source |
|---|---|---|
| Status | Live. A 2025/2026 cycle closed 15.06.2025 | `dp.edu.az` |
| Legal basis | Presidential Decree No. 2931 (30.09.2021); Order No. 3163 (28.02.2022) | Order text, ILO NATLEX `AZE-117984.pdf` |
| Administering body | State Programme Management Group (**DPİQ**) under the Ministry of Science and Education | Order §2; `dp.edu.az` |
| Monitoring body | **Ministry of Economy**, on the Ministry of Science and Education's order | Order §3 |
| Reporting | Annually, to the President | Order §2.2 |
| **Funder** | **SOFAZ — the State Oil Fund**, plus international assistance, loans, grants and donations | `oilfund.az/en/projects/14` |
| 2026 allocation | **AZN 92.729 million**, execution rate 13.2% at H1 2026 | same |
| Ceiling | "annually **no more than 500 people** … at the **Bachelor's and Master's** levels" | same |

**The ~500 figure is a ceiling, and master's is inside it.** That settles the three-figure question
the plan was told to ask: it is not an award count and not a realised enrolment.

**The funder is the sovereign wealth fund, not the education budget.** SOFAZ publishes an allocation,
an execution rate and a cumulative disbursement series — an audited financial trail no other
government scholarship in this corpus has. If per-cycle award counts are ever needed, this is the
likeliest place they exist.

## 3. Not found — stated as unfound, not as absent

**The return-service obligation is not in the Order.** The full text retrieved from ILO NATLEX (8
pages) carries no return, service or repayment clause. It therefore lives in the Cabinet-approved
rules (`qaydalar`) or in the individual contract, and `e-qanun.az` is where to look. **This is the
single most important thing the runs must produce**, and this note deliberately does not answer it.

**A name discrepancy the runs should settle.** The same FAQ routes cost-coverage applicants to the
management group of the *"2022-2028-ci illər üçün Azərbaycan Respublikasında ali təhsil sisteminin
beynəlxalq rəqabətliliyinin artırılması üzrə Dövlət Proqramı"* — the State Programme on increasing
the **international competitiveness of the higher education system** — which is a different title
from the youth-abroad programme. Either two programmes share one management group, or the FAQ is
loose. Adjacent programmes sharing an administrator is exactly the shape that produced the last
conflation.

**Lead, not fact:** that a 2026/2027 cycle is open and that the Ministry has published its approved
university and programme list for 2026/2027. This rests on an agency report, not on the Ministry's
own page. The runs must confirm it at source or state the last cycle they can evidence.

## 4. Heydar Aliyev — separate, and here is why they got merged

Sourced from `studyinazerbaijan.edu.az/financial-support`:

| | State Programme (outbound) | Heydar Aliyev grant (inbound) |
|---|---|---|
| Who is eligible | Azerbaijani citizens | Foreign nationals — OIC, Non-Aligned Movement, Small Island Developing States, and countries with cultural/ethnic/historical ties to Azerbaijan |
| Who pays | SOFAZ | Azerbaijani state, via MFA + Ministry of Science and Education |
| Direction | Out of Azerbaijan | Into Azerbaijan |
| Scale | ≤500/year, BA and MA | 100 grants/year, five years from 2026-27 |
| Route | Apply to DPİQ **with an admission already held** | Nominated by the applicant's **own** government, then apply via SIACAS |
| Basis | Decree 2931 / Order 3163 | Presidential decree, 8 July 2023 |

**They share `portal.edu.az`.** So does HTP, the intergovernmental programme covered by the
origin-side run. Three distinct instruments, three funding directions, one portal — which is a
sufficient explanation for how prior research merged two of them, and a standing hazard for the runs.

## 5. What the adjudication should check

Written before the runs, so these are honest tests rather than hindsight:

1. **Does either run find the "no admission is carried out" clause?** It is one sentence in an FAQ,
   it is not in the Order, and it changes what the instrument is. A run that describes the State
   Programme as a way to study abroad without it has missed the operative fact.
2. **Does either run reach the return-service provision**, and does it quote it? This note could not.
3. **Does either run name SOFAZ as the funder**, or does it assume the education ministry pays?
4. **Does either run label the 500 correctly as a ceiling**, or report it as awards made?
5. **Does either run keep HTP, DP and Heydar Aliyev apart** while all three sit on `portal.edu.az`?
6. **Does either run notice the competitiveness-programme name discrepancy**, or silently pick one?

A run that disagrees with this note is not thereby wrong — this note is one pass, and §2's status
line is the weakest thing in it. But a run that is *silent* on items 1, 2 and 3 has not covered
Part A, whatever else it contains.
