# CSC (Chinese Government Scholarship)

China's government scholarship. [src: 2026-08-27-instrument-landscape-synthesis.md] See [China](../countries/cn.md), [instrument landscape](../topics/instrument-landscape.md), [corridor mechanics round 2](../topics/corridor-mechanics-round2.md).

- Type A is applied for directly and selected jointly; there is no single global deadline. [src: 2026-08-27-instrument-landscape-synthesis.md §2] [src: 2026-08-27-instrument-landscape-synthesis.md §3]
- Four-digit agency codes link university, track and central record and must be parsed by the extractor. [src: 2026-08-27-instrument-landscape-synthesis.md §7]
- Applicant counts are not published; the "about 30,000 a year" figure is agency-sourced, not official. [src: 2026-08-27-instrument-landscape-synthesis.md §4]
- Both runs agree it can substitute for visa financial proof. [src: 2026-08-27-corridor-mechanics-synthesis.md §2]
- Run 2's 2018 figure of 63,041 holders (12.81%, up from 49,022 in 2016) replaces run 1's 2014 figure of 36,943 (9.80%); both are enrolment stock with no applicant denominator. [src: 2026-08-28-corridor-mechanics-round2-synthesis.md §3]
