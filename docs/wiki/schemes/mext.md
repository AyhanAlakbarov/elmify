# MEXT (Japan)

Japan's government scholarship. [src: 2026-08-27-instrument-landscape-synthesis.md] See [Japan](../countries/jp.md), [instrument landscape](../topics/instrument-landscape.md), [corridor mechanics round 2](../topics/corridor-mechanics-round2.md).

- MEXT runs an embassy track and a university track with different quotas, deadlines and selectors. [src: 2026-08-27-instrument-landscape-synthesis.md §2]
- It has no single global deadline; dates live at embassy or course level. [src: 2026-08-27-instrument-landscape-synthesis.md §3]
- Applicant and award counts are not published. [src: 2026-08-27-instrument-landscape-synthesis.md §4]
- MEXT's own documents state rates: more than 20倍 for the embassy-mission track (2026 self-inspection PDF), about 2-3倍 for master's courses and a 10倍 policy goal; run 1 found none, and only the first is current. [src: 2026-08-28-corridor-mechanics-round2-synthesis.md §3]
- Those rates sit at rung 2 as publisher-stated, a `FundingBand` input, and need the year attached. [src: 2026-08-28-corridor-mechanics-round2-synthesis.md §3] [src: 2026-08-28-corridor-mechanics-round2-synthesis.md §5]
- MEXT publishes recipient aggregates only. [src: 2026-08-28-corridor-mechanics-round2-synthesis.md §4]
