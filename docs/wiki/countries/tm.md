# Turkmenistan

See [origin side](../topics/origin-side.md) and [nationality-keyed](../topics/nationality-keyed.md).

- Turkmenistan publishes a live, in-person selection channel for foreign study (documents accepted 1 to 15 December 2025), and it is bachelor's-level, so for a master's product it yields nothing. [src: 2026-08-29-origin-side-synthesis.md §9]
- The nomination carries an 18-to-25 age band and a military-unit character reference. [src: 2026-08-29-origin-side-synthesis.md §5]
- Under plain fetch `education.gov.tm` returns a 2,143-byte JavaScript shell and two different announcements return byte-identical HTML; only a browser render shows the announcement. [src: 2026-08-29-origin-side-synthesis.md §9]
- [Fulbright](../schemes/fulbright.md): master's, one or two years, deadline 31 May 2026, at least 2 years' full-time post-graduate experience; AI-generated or plagiarised essays are disqualified. [src: 2026-08-29-fulbright-per-country-verification.md §1] [src: 2026-08-29-fulbright-per-country-verification.md §4]
- [GKS](../schemes/gks.md): Embassy Track quota 7; University Track General is a dash, meaning not offered on that track (R-GKS only, 3). [src: 2026-08-29-gks-quota-primary-verification.md §2] [src: 2026-08-29-gks-quota-primary-verification.md §3]
- [ADB-JSP](../schemes/adb-jsp.md) lists Turkmenistan; JJ/WBGSP does not. [src: 2026-08-29-nationality-keyed-synthesis.md §2] [src: 2026-08-29-nationality-keyed-synthesis.md §5]
- IsDB's M.Sc. LDMC list does not include Turkmenistan. [src: 2026-08-29-gapfill-openitem-verification.md §1]
- Stipendium Hungaricum is `NOMINATED` for Turkmenistan. [src: 2026-08-29-origin-side-synthesis.md §1]
