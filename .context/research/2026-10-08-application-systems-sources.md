# Application systems seed: sources and verification (2026-10-08)

Companion to `2026-10-08-application-systems-draft.csv` (42 rows: 25 NATIONAL, 17 VENDOR).

Method. "Loaded" = page body read this session via curl, Scrapling, Tavily extract, or an Exa search result whose highlights quote the page. Rows marked (Exa) rest on search-result highlights from that URL, not a full page read. A field is empty when no loaded official page states it. Empty `ranked`/`one_fee_per_round`/`choice_limit`/`prep_lead_days` on a VENDOR row means "not applicable to the vendor", not "unknown". `prep_lead_days` is empty everywhere except uni-assist: no other system states one.

Scholarship applications (not degree applications), kept in the CSV: gks-korea, csc-china, stipendium-hungaricum, turkiye-burslari, daad-portal, si-scholarships, chevening, fulbright-iie. Note: Stipendium Hungaricum, Turkiye Burslari and Fulbright-IIE embed university placement (the scheme applies for you); SI needs the 8-digit universityadmissions.se number first; Chevening, DAAD, CSC type B are applied for in parallel with or before the degree application.

## NATIONAL rows

- universityadmissions-se. Confirmed: choice_limit 4 ("You can select up to four master's programmes", rises to 5 after selection results; bachelor's is 8) at /apply-to-masters/search-for-courses-and-programmes-masters/; ranked true (/rank-your-selections-masters/: lower-ranked deleted once a higher one offers); one_fee true (/pay-your-application-fee-non-eueea-masters/: SEK 900, "just one time" per semester across all programmes). antagning.se is the Swedish-language site of the same service (www.antagning.se redirects to /se/start; loaded). Empty: prep_lead_days (not stated).
- studyinfo-fi. Confirmed (loaded via Scrapling): up to six programmes per joint application; one_fee true (https://opintopolku.fi/konfo/en/sivu/application-fee: EUR 100 for non-EU/EEA applicants, one fee covers all applications for the same start term). ranked left empty because it varies: spring English-taught round is unranked, autumn round and Finnish/Swedish spring round are ranked. studyinfo.fi redirects to opintopolku.fi (loaded).
- studielink-nl. Confirmed: up to four enrolment applications per academic year, of which at most one or two numerus fixus (Studielink PDF, loaded). Host www.studielink.nl loaded (SPA shell). Empty: ranked (not stated), one_fee (Studielink itself charges no fee as far as seen but no page states it).
- uni-assist-de. Confirmed (deadlines-processing-time page): evaluation "usually 4 to 6 weeks" counted from receipt of the application, so prep_lead_days 42 as instructed; the page also recommends applying "at least 8 weeks before the deadline" (56 days), which the field spec did not use. one_fee false (pay-all-fees FAQ: EUR 75 first course, EUR 30 each additional course in the same semester). Hosts: www.uni-assist.de and my.uni-assist.de (My assist), both loaded. Empty: choice_limit, ranked (not stated).
- hochschulstart-de. Confirmed: up to 12 "Studienangebote" (programme+university); ranked true ("Priorisieren"; unprioritised order of submission is used). Note: DoSV covers mainly bachelor's and local-NC programmes; most master's are applied for per university. Empty: one_fee (not stated).
- monmaster-fr. Confirmed (Exa, information.monmaster.gouv.fr/candidater/ and enseignementsup-recherche.gouv.fr): 15 vœux (counted per master mention per institution) plus 15 for work-study; 10 each in the complementary phase. The page returned 403 to curl, so loaded only as search highlights. Empty: ranked (commissions rank candidates; whether the candidate ranks vœux was not shown), one_fee. Applies to students resident in France or in countries not covered by Etudes en France.
- etudes-en-france. Confirmed: platform page pastel.diplomatie.gouv.fr loaded (login page lists Azerbaijan among covered countries); choice_limit 7 for L2/L3/master from the official Campus France Mali page ("7 choix pour les formations au-delà de la première année"), which is a country site of Campus France, not the platform page itself. campusfrance.org/en is the agency site (the separate "Campus France" request is covered by this one row). Empty: ranked (stated "à classer par priorité" only for L1/DUT in the FAQ seen), one_fee (fees vary by country Campus France office; "frais de dossier" only if admitted per CampusArt text, not for the main procedure).
- universitaly-it. Loaded universitaly.it/it/studenti-stranieri (portal is "gratuito", the only channel for pre-enrolment of non-EU applicants). choice_limit left empty: three university guides (Unibo, Unimore, UPO) say one pre-enrolment per applicant per year, but Universitaly's own page did not state it and a third-party site says three. Treat as 1 pending a Universitaly source. ranked/one_fee empty (a fee does not exist per the page, but not stated as such for this field).
- optagelse-dk. Confirmed (lifeindenmark.borger.dk, official Danish agency text, loaded): up to 8 programmes in a priority list. Host www.optagelse.dk loaded; it also offers "Apply for higher education programmes taught in English". Note: master's applicants apply directly to universities (earlier research, SDU/AAU pages); this row is for bachelor's/professional bachelor's. Empty: one_fee.
- samordna-opptak-no. Confirmed (samordnaopptak.no/om/hvaersamordnaopptak.html, loaded): up to ten studies in priority order. Apply portal host sok.samordnaopptak.no (link on the homepage, loaded). Note: undergraduate and some professional master's; most master's go through each institution's Soknadsweb. Empty: one_fee.
- ucas-undergraduate. Confirmed (loaded): five choices; fee GBP 34.50 for the 2027 cycle covers up to five (six for conservatoires): one_fee true. Empty: ranked (UCAS shows choices without stating a ranking).
- ucas-postgraduate. Confirmed (loaded): "You apply directly to the provider for postgraduate courses"; UCAS is a search tool, with exceptions (conservatoire, teacher training in Wales/Scotland, social work/nursing/medicine MA/MSc, accelerated LLB). All policy fields empty on purpose.
- pac-ie. Loaded www.pac.ie: "PAC has ceased to trade from September 30th 2024". Row kept so the catalogue knows the host is dead; all policy fields empty.
- cao-ie. Confirmed (loaded FAQ): 10 choices on Level 8 list and 10 on Level 7/6 list; genuine order of preference required (ranked true). Empty: one_fee (fee not retrieved).
- ouac-ca. Confirmed (Exa, ouac.on.ca/guide/undergrad-fees/, curl got 403): base fee CAD 159 covers first 3 choices, CAD 51 per additional choice, so one_fee false; the only cap is 3 programme choices at any one university, no overall limit, so choice_limit empty. Empty: ranked.
- uac-au. Confirmed (loaded): up to 5 preferences undergraduate (6 for postgraduate and international Year 12), in order of preference; one application fee (A$82 early, A$215 after 30 Sept 2026; Exa for fee). Row set to 5 (undergraduate).
- vtac-au. Confirmed (loaded help page): up to eight courses, ranked; single course application processing fee, no extra charge for changing preferences (fees at vtac.edu.au/dates, Exa). International applicants may only use VTAC if international Australian Year 12 students.
- gks-korea. Confirmed (loaded www.studyinkorea.go.kr/en/plan/scholarship.do): embassy track up to THREE universities, at least one Type B, one department per university; online application on the Study in Korea site. University track applies directly. Empty: ranked, one_fee (not stated).
- csc-china. Loaded studyinchina.csc.edu.cn (login, via Tavily) and www.csc.edu.cn/laihua. Type A (embassy) vs Type B (university, agency number) from a Slovak university's CGSIS guide (Exa), not an official CSC page. Empty: all policy fields (CSC pages do not state a choice limit).
- stipendium-hungaricum. Confirmed (loaded stipendiumhungaricum.hu/apply/): "only 2 choices are allowed" among 30 institutions; priorities have an order (cannot be edited after submission): ranked true. Host apply.stipendiumhungaricum.hu loaded and shows "DreamApply student admission software". Empty: one_fee.
- turkiye-burslari. Loaded tbbs.turkiyeburslari.gov.tr (login) and turkiyeburslari.gov.tr/fulltimeprograms (applications via TBBS 10 Jan to 20 Feb; "ensures university placement"). choice_limit left empty because the official domain carries conflicting statements: two "sayfa/how-to-apply..." articles on turkiyeburslari.gov.tr say "up to 12 programs" (Exa), which looks like low-quality CMS content, while earlier background knowledge said 6. Needs a primary guide.
- daad-portal. Loaded meindaad.de help pages (Exa/curl): application portal via www.meindaad.de, "Personal Funding" area; the degree application is separate for most programmes. Empty: all policy fields.
- si-scholarships. Confirmed (si.se page, Exa highlight; also apply-scholarships.si.se loaded, which is DreamApply-powered): scholarship application can include up to four eligible master's programmes; needs the 8-digit universityadmissions.se application number; portal open 9-25 Feb 2026 in the last cycle. Empty: ranked, one_fee.
- chevening. Confirmed (loaded chevening.org guidance): three UK master's course choices "in order of preference" (ranked true). Application portal host is not shown on pages read (only "link to the application portal" by email), so hosts lists www.chevening.org only. Empty: one_fee.
- fulbright-iie. Confirmed (US embassy instructions PDF via Exa; apply.iie.org/ffsp2027 loaded): list up to four institutions "in priority order"; IIE-placed applicants do not apply to universities themselves. Empty: one_fee.
